## 모델과 저장 구조

종목별 팩터 점수를 공통으로 만들고, 투자 전략과 위험 분석에서 각각 다른 수익률을 계산한다.

| 테이블 | 정의와 용도 |
|---|---|
| `factor_score_daily` | 종목·거래일·팩터·모델 버전별 점수. 원지표, 사용 지표 수, 결측 사유, 데이터 기준 시각을 추적한다. |
| `factor_return_daily` | 지수 구성 종목 중 팩터 상위 N%로 만든 롱온리 포트폴리오의 일별 총수익률에서 같은 지수의 일별 총수익률을 차감한다. 초기 가설은 상위 20%, 동일 비중, 월 1회 리밸런싱이다. 같은 지수의 전체 구성 종목을 동일 비중으로 담은 비교군도 계산해 가중 방식의 효과를 구분한다. |
| `risk_exposure_daily`, `risk_factor_return_daily` | `build_and_regress_aug`에서 전일 노출과 당일 종목 총수익률을 사용해 시장·업종·스타일의 일별 팩터 수익률과 종목 잔차를 가중 횡단면 회귀로 추정한다. 업종 수익률의 시총 가중합을 0으로 제약한다. |
| `risk_covariance_daily`, `risk_specific_variance_daily` | `run_risk_decomposition`에서 팩터 수익률 공분산과 종목별 잔차 분산을 갱신한다. 포트폴리오의 공통 팩터 위험과 고유위험, 벤치마크 대비 추적오차를 계산한다. |

ETF의 팩터 노출은 보유 종목 비중으로 점수를 가중 집계하고, 유효 점수가 있는 보유 비중도 표시한다. 실현 팩터 기여도는 전일 포트폴리오 노출과 당일 회귀 팩터 수익률의 곱으로 계산한다. 예상 위험은 포트폴리오 팩터 노출 `x`와 팩터 공분산 `F`, 종목 비중 `w`와 고유 공분산 `D`로 `xᵀFx + wᵀDw`를 계산한다. 첫 버전에서 `D`는 종목별 잔차 분산을 담은 대각행렬로 둔다. 추적오차에는 포트폴리오와 벤치마크의 비중 차이를 사용한다. ## 팩터 정의 초안

`↑`는 원값이 높을수록, `↓`는 낮을수록 점수가 높다는 의미다.

| 대팩터 | 상세 팩터 | 세부 지표와 방향 |
|---|---|---|
| 가치 | 가격 매력 | TTM 순이익 / 시총 ↑, 자기자본 / 시총 ↑, TTM FCF / 시총 ↑ |
| 퀄리티 | 수익성 | TTM 매출총이익 / 평균 총자산 ↑, ROE ↑ |
| 퀄리티 | 현금흐름 | 현금 기반 영업수익성 ↑, FCF 마진 ↑, 영업발생액 / 평균 총자산 ↓ |
| 안정성 | 평소 흔들림 | 특이 변동성 ↓. 최근 60거래일 시장·업종 조정 잔차의 표준편차 |
| 안정성 | 급등 · 재무 여력 | `MAX` ↓. 최근 21거래일의 최대 일간 수익률. 현금성 자산 / 총자산 ↑ |
| 모멘텀 | 상승폭 · 상승의 꾸준함 | 12–1개월 총수익률 ↑. 같은 구간에서 양의 수익률을 기록한 거래일 비율 `positivity` ↑ |
| 성장 | 실적 개선 · 실적 전망 | `실제 EPS − 발표 직전 컨센서스 EPS`를 발표 전 주가로 나눈 어닝 서프라이즈 ↑. 동일 회계기간 EPS 컨센서스의 최근 30일 변화 ↑ |
| 규모 | 기업 규모 | 로그 시가총액 ↑. 양수는 대형주 노출을 뜻하며, 소형주 전략은 점수 방향을 뒤집는다. |
| 배당·주주환원 | 배당 · 희석 | 최근 12개월 현금배당 / 주가 ↑, 분할 조정 발행주식 수의 전년 대비 증가율 ↓ |

영업발생액, 특이 변동성, `MAX`, 발행주식 수 증가율의 방향은 검증할 초기 가설이다. `MAX`는 큰 상승일을 측정하므로 급락을 포착하려면 하방 변동성을 별도 지표로 둔다. 성장 팩터의 초기 두 지표는 기대 대비 실적과 기대치 변화를 측정한다. 실현 성장률이 필요하면 매출 또는 영업이익의 전년 대비 성장률을 별도로 추가한다.

## 점수 계산과 시점 규칙

1. 계산 마감 시각을 고정하고 `available_at`이 마감 이전인 값만 사용한다. 결산일, 공개 시각, 벤더 제공 시각, 정정 버전을 보존한다. 공개일만 있으면 다음 거래일부터 반영한다. 장 마감 뒤 만든 점수는 다음 거래일의 가정 체결 시점부터 전략 수익률에 반영한다.
2. 당시 공개된 최근 4개 분기에서 TTM을 계산한다. 재무상태표는 지표에 따라 최근 값 또는 기간 평균을 쓴다. 음의 자기자본에서 계산한 ROE, 0에 가까운 분모, 금융업 FCF는 적용 조건을 명시한다.
3. 시장과 거래일별로 1·99 분위수 윈저라이즈 → z-score → 방향 적용 → 상세 팩터 평균 → 대팩터 평균을 계산한다. 각 합성 단계는 동일 비중을 초기값으로 사용하고, 유효 지표 수가 최소 기준에 못 미치면 `NULL`을 남긴다. 원지표와 실제 사용 지표 수를 보존한다.
4. 지수는 당시 유효한 구성과 비중을, ETF는 당시 공개된 보유 내역을 사용한다. 편입·편출, 상장폐지, 종목 식별자 변경을 시점별로 재현한다. 주가와 시총에는 해당 시점의 단위를 맞추고, 총수익률에는 배당과 기업행위를 반영한다.

| 기존 FnGuide 재무 적재본 | 현재 팩터 백테스트 입력이 미래 참조와 생존 편향을 만들 수 있어 과거 유실 데이터를 보충하는 방안 고려 | 최초 공개 값과 정정 이력, 당시 가용 시각, 과거 상장폐지 종목을 각각 확인한다. 누락 관측값 보충과 당시 버전 복원을 별도로 검증한다. |
| 미국 CIQ | 한국 CIQ와 미국 CIQ를 구분해 평가 | 한국 데이터에서 관찰한 차이를 미국 데이터 전체의 결론으로 확대하지 않는다. 미국은 현지 보고 기준·표준화 항목·시점 이력을 별도로 검증한다. |

국내 재무와 지수 데이터의 소스 후보로 QuantiWise를 우선 비교하는 이유는 국내 보고 기준과 커버리지, 지수 구성 종목 코드의 정합성이다. 한국과 미국은 원천별 수집·정의 매핑을 구분하고, 팩터 입력의 공통 스키마에서 회계 기준과 원천 항목 정의를 추적하는 방향으로 검토한다. 소스 선택은 아직 확정하지 않았다.

### 백테스트 시점과 누락 데이터 검증

과거에 유실된 재무 관측값을 채우는 작업과 point-in-time 재현을 함께 검토한다. 각 값에 결산기간, 최초 공개 시각, 정정 버전, 원천 제공 시각, 적재 시각을 보존하고 계산 기준일에 실제 이용할 수 있었던 버전을 선택한다. 현재 정정된 값을 과거 날짜에 채우면 미래 참조가 발생할 수 있다. 과거 투자 유니버스에는 상장폐지·편출 종목도 포함해 생존 편향을 별도로 검증한다. 이는 사용자 우려에 대한 구현 검토 항목이다.

### 삼성전자 샘플 검증

사용자가 제시한 기간 표기는 `YTD ~ CPD - 1TD`이며 원문 그대로 보존한다. CPD의 정확한 정의와 YTD 범위의 거래일 처리는 후속 작업에서 확인한다.

| 일자별 필드 | 확인할 내용 |
|---|---|
| 코스피200 소속 여부 | 해당 일자의 유효한 편입·편출 이력과 기준일 |
| 코스닥150 소속 여부 | 해당 일자의 유효한 편입·편출 이력과 기준일 |
| 거래정지 여부 | 상태의 효력 발생·해제 시점과 조회·주문 기준 시각 |
| 관리종목 여부 | 지정·해제 이력과 해당 시점의 분류 |

삼성전자를 첫 시계열 검증 샘플로 사용한다. 이후 편입·편출, 거래정지·해제, 관리종목 지정·해제가 실제 발생한 종목으로 상태 전환도 확인한다. 모든 샘플을 종목 코드, 내부 증권 식별자, 기준일, 원천, 효력 시각으로 연결한다.
