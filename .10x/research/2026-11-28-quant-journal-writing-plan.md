# 퀀트 실험 설계 연구 글 집필 계획

원자료는 [14개 출처 비교와 설계안](2026-11-28-quant-source-comparison-and-fintos-design.md)과 기존 FINTOS 매매·분류 연구 기록이다. 원고는 site/journal/2026-11-28-quant-research-design/index.html에 작성한다.

1. 초록과 연구 질문에 리뷰 범위와 제안의 상태를 명시한다.
2. 관련 연구를 사건·관계 신호, 백테스트의 선택 편향과 재현, 체결·운영으로 나눈다. 핵심 논문마다 설계, 보고한 결과, 적용 한계를 연결한다.
3. 14개 출처의 산출물 비교와 공통점·차이 표를 싣는다. 일관된 번호로 참고문헌의 원문에 연결한다.
4. 기존 TRACE 매매 실험과 별도 분류 실험을 구분한다. 신규 실험은 비교군, 가용 시점, 비용, 지표, 독립 검증 순서, 템플릿으로 설명한다. 미정 항목은 확정값처럼 쓰지 않는다.
5. 정적 사이트를 빌드해 홈·보관함 등록, 글 내부 앵커, 인용 연결과 표 구조를 확인한다.

검증: 정적 빌드에서 홈·연구 보관함 등록, 표 6개, 참고문헌 16개와 인용·내부 링크를 확인했다.
