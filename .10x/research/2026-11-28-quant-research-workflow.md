# 퀀트 트레이더의 연구 방식과 실험 기록 양식

## 조사 질문과 범위

퀀트 트레이더는 무엇을 분석하며 아이디어를 어떤 실험을 거쳐 검증하는가? 공개된 실제 직무 설명, 연구 프로토콜, 거래 자료를 사용한 논문, 실험 플랫폼 문서를 비교했다. 공개 자료는 회사 내부 회의 주기, 전략별 비중, 실제 승인 기준을 보여주지 않는다. 아래 업무 흐름과 양식은 여러 출처를 종합한 제안이다.

## 직무별로 다른 검증 대상

| 업무 | 반복하는 분석 | 판단에 쓰는 결과 |
| --- | --- | --- |
| 주식 알파·팩터 | 수익률·거래량·공시·이벤트 신호, 순위 상관, 분위별 수익, 정보가 사라지는 속도 | 시간순 표본 밖 성능, 종목군·시기별 강건성, 비용 차감 성과 |
| 포트폴리오 | 기존 전략과 상관·중복 노출, 업종·시장·스타일, 포지션 규모, 회전율, 리밸런싱 | 동일한 위험·노출 예산에서의 증분 가치, 낙폭, 집중, 거래 가능 규모 |

| 운용·모니터링 | 예상과 실측 주문·체결 대조, 신호 드리프트, 손익을 신호·노출·비용으로 분해 | 중단 또는 축소 사유, 문제가 생긴 종목과 세션, 대응 기록 |

Jane Street의 공개 트레이더 직무에는 신호 발굴, 통계 분석, 알고리즘 시스템, 전략 실행 및 리스크 관리가 함께 나온다. AQR 연구는 실제 기관 주문으로 시장 충격·비용 후 수익·운용 규모의 관계를 분석했다. QuantConnect 문서는 운용 결과와 같은 시기의 표본 밖 재실행을 대조하는 사례를 제공한다. 이 자료들은 역할의 사례이며 모든 데스크의 업무 분포를 뜻하지 않는다.

## 실험을 진행하는 순서

1. **가설과 반증 조건을 한 문장씩 쓴다.** 관찰한 경제 현상, 누가 어떤 정보에 늦게 반응하는지, 어느 종목과 보유기간에 나타날 것인지 기록한다. 주요 지표와 채택 기준은 테스트를 열기 전에 정한다.
2. **당시 정보와 종목군을 복원한다.** 공시 공개 시각과 수집 시각, 당시 알려진 정정본, 당시 투자 가능 종목, 상장폐지·분할·배당·거래정지를 복원한다. 신호를 보았을 시각과 주문이 가능해지는 시각 사이에 식별 가능한 시차를 둔다.
3. **싼 실험으로 신호를 분해한다.** 가격-only, 직접 공시, 관계를 단계적으로 추가한다. 같은 종목·날짜에 신호를 모두 계산해 순위 상관, 방향 성능, 커버리지와 보유기간별 감쇠를 측정한다. 위약검정은 업종·규모가 비슷한 무관계 기업으로 바꾸거나 관계를 시점 제약 아래 섞어 비교한다.
4. **시간순으로 평가하고 모든 시도를 기록한다.** 과거 학습, 그 다음 검증, 마지막 미사용 테스트로 나눈다. 대상 수익률 구간이 경계를 넘으면 겹치는 학습 행을 제외한다. 하이퍼파라미터, 규칙, 종목군 변형과 실패도 기록한다. 이미 읽은 테스트를 보고 규칙을 바꾸면 해당 구간을 탐색으로 표시하고 새 구간에서 확인한다.
5. **주문과 비용을 넣는다.** 주문 가능 시점, 가격, 최대 체결량, 거래정지, 부분 체결·미체결, 수수료·스프레드·슬리피지·시장 충격을 명시한다. 두 전략의 시장 노출 또는 위험을 맞추고 거래가 없던 날에도 손익 장부를 이어 간다. 공매도, 조달, 환전이 있는 전략은 해당 비용도 넣는다.
6. **차이와 실패 원인을 검토한다.** 총 수익뿐 아니라 같은 날의 기준 대비 차이와 불확실성, 최대낙폭, 회전율, 실제로 바뀐 주문 수를 보고한다. 거래일을 비교 단위로 삼을 경우 당일 종목을 함께 묶고, 시계열 의존성이 있으면 블록 재표집 등을 검토한다. 강세·약세, 유동성, 특정 종목 제외 등 사전 정의한 민감도 분석을 적용한다.
7. **결정과 재실행 경로를 남긴다.** 보류·기각·새 표본 검증·모의 운용 중 하나를 이유와 함께 기록한다. 모의·실거래 비교에서는 데이터 도착, 신호, 주문, 체결, 비용 중 처음 차이가 생긴 지점을 찾는다.

## 복사해서 쓰는 실험 카드

```markdown

## 실행 전
- 가설과 경제적 이유:
- 기각할 관찰:
- 종목군/기간/거래소/캘린더/통화:
- 데이터·그래프 스냅샷 / 시세 공급원 / 결측·상장폐지 처리:
- 사건 발생 / 공개 / 수집 / 신호 동결 / 최초 주문 가능 시각:
- 학습 / 검증 / 미사용 테스트 / 겹치는 레이블 처리:
- 기준 모형 / 바꿀 입력 하나 / 음성 대조 / 동일 평가 키:
- 주문 방식 / 비중·위험 한도 / 체결 규칙·수수료·충격:
- 주 지표 / 최소 의미 효과 / 채택·보류 조건:
- 사전 계획 동결일 / 코드 커밋 / 설정·데이터 해시 / 실행 명령:

## 실행 후
- 실험별 표본 / 신호 수 / 신호 변경 수 / 주문 변경 수 / 체결 수:
- 기준 대비 주요 지표 차이 / 불확실성 / 비용 후 성과:
- 낙폭 / 시장·업종 노출 / 회전율 / 거래 가능 규모:
- 비용·시차·관계 정의·상위 종목 제외 민감도:
- 실패·제외 사례 / 계획 밖 변형 / 반복 테스트 횟수:
- 결정과 근거 / 재현 산출물 경로 / 새 검증을 시작할 조건:
```

## FINTOS에서 바로 대입할 사례

가설은 이미 공개되어 유효한 공급계약을 통해 전달된 거래 상대 공시가 대상 기업의 직접 공시를 넘어 증분 신호를 제공한다는 것이다. 실험에서는 가격, 가격+직접 공시, 가격+직접 공시+거래 경로를 같은 종목·거래일에 비교한다. 공급계약의 유효시점과 당시 알려진 시점을 구분하고 원문 접수번호와 관계 경로를 저장한다. 주문 위험량은 동일하게 맞추고, 무관계 대조군, 지연 체결, 비용 민감도를 따로 본다.

기존 TRACE 개정 실험에서는 39거래일·659개 종목-거래일에서 거래 경로의 정확도가 직접 공시에 비해 0.15%p 낮았다. 거래일 단위 95% 재표집 구간은 −1.66~+1.71%p였다. 해당 표본은 이미 결과를 확인했다. 앞으로 다른 정의를 적용하면 그 비교는 탐색으로 기록하고 새 구간에서 다시 평가한다. 고객·공급사 정보 전이는 Cohen·Frazzini의 연구에서 동기를 얻을 수 있으나, 그 연구 결과가 한국 공시 전략의 성과를 보장하지 않는다.

## 한계

공개 자료에 기초한 실무 패턴 조사다. 팀별 시간 배분, 거래 승인 절차와 내부 템플릿은 확인하지 못했다. 지표·비용 모형·합격 기준은 전략의 보유기간, 유니버스, 시장과 주문 규모에 맞춰 결정해야 한다.
