# 퀀트 연구 실무 비교와 FINTOS 실험 설계안

[기존 조사와 실험 카드](2026-11-28-quant-research-workflow.md)를 확장했다. 공개 직무와 현업 사례, 학술 연구, 플랫폼 구현, 성과 보고 자료를 비교했다. 회사 내부의 승인 기준이나 하루 일정은 이 자료로 확인할 수 없다. FINTOS 적용 부분은 실행 전 설계안이다.

| [Jensen·Kelly·Pedersen](https://www.nber.org/papers/w28432) | 동일한 팩터 정의를 유사 주제로 묶고 여러 시장에서 재현한다. | 정의를 고정한 기간·시장·종목군 재현 행렬. | 같은 기업과 충격을 공유하는 표본은 독립 재현으로 볼 수 없다. |

## 공통점과 차이

| 축 | 공통 | 차이 | FINTOS 적용 |
| --- | --- | --- | --- |
| 비교 단위 | 비교 조건과 대조군을 명시한다. | 이벤트 연구는 공시·사건, 예측은 종목·세션, 포트폴리오는 거래일, 실행은 주문·체결 단위다. | 네 단위를 분리하고 식별자로 연결한다. |
| 시점 | 미래 정보를 넣지 않는다. | 사건창은 시장 반응을, 주문창은 체결 가능성을 본다. | 발생·공개·관측·신호 동결·주문 가능 시각과 관계 유효일을 구분한다. |
| 대조 | 경쟁 설명을 시험한다. | 관계 위약은 연결의 의미를, 노출 대조는 현금·시장 비중 차이를 검증한다. | 대조군 두 개를 따로 구성하고 비용·출처·가용 시점은 공통으로 적용한다. |
| 성공 지표 | 측정 범위와 가정을 남긴다. | 초과수익, 분류, 순손익, 실행 비용은 서로 대체할 수 없다. | 매매는 비용 후 증분 손익, 분류와 커버리지는 진단 지표로 둔다. |
| 재검증 | 데이터 판본과 실패도 기록한다. | 학술 재현은 새 기간·시장, 운영 검증은 동일 기간의 모의·실측 차이를 본다. | 과거 재현, 독립 검증, 새 공시 모의 운용을 구분한다. |

## FINTOS 적용 설계

**가설.** 공급계약 또는 비교 가능한 금액 정정 공시에 명시된 상장 구매자를 대상으로, 공시 전에 알 수 있었던 유효 계약 경로를 추가로 요구하면 명시 구매자 공시만 쓰는 정책보다 비용 후 순성과가 개선되는가? 이 비교의 대상은 경로 필터의 증분 효과다. 별도 거래처까지 전파하는 가설은 평가를 분리한다.

기존 두 종목 39거래일에서 가격 추세 −7.69%, 명시 구매자 −27.03%, 유효 경로 −5.26%였다. 경로군과 구매자군의 보유 종목·일은 각각 18과 52로 달랐다. 이미 확인한 구간에서 규칙이 추가됐으며, 원형 이동 150개 비교도 독립 표본이 아니다. 차이가 경로 정보에서 나왔는지 현금 비중에서 나왔는지는 이 결과로 확정할 수 없다. 별도 로지스틱 분류 실험의 −0.15%p는 평가 정책·단위가 다르다. [기존 매매 실험](../../docs/research/quant_kg_experiment_results.md) · [기존 분류 실험](../../docs/research/trace_economic_revision_2026.md)

| 비교군 | 바꾸는 요소 | 판단할 질문 |
| --- | --- | --- |
| A0 매수 후 보유 | 최초 배분 후 유지 | 전체 시장·보유 성과의 맥락 |
| A1 가격 추세 | 가격 규칙만 사용 | 단순 거래 기준 |
| A2 가격 + 명시 구매자 | 같은 정책에 공시상 구매자 신호를 추가 | 직접 공시만으로 달라지는 것 |
| A3 가격 + 구매자 + 유효 경로 | A2에 기존 공개·유효 계약, 역할과 품목 조건을 추가 | **주 비교 A3−A2** |
| 관계 위약 | 시점별 업종·규모·유동성이 비슷한 무관계 연결로 대체 | 실제 연결이 추가 가치가 있는가 |
| 노출 대조 | 사전에 정한 위험·노출 예산으로 가격 또는 공시 대조군을 구성 | 더 적게 투자한 효과가 얼마나 설명하는가 |

관계 위약은 매칭 가능한 사건만으로 A3와 짝지어 평가하고 제외율을 보고한다. 연결 차수·방향·시간과 종목군을 가능한 범위에서 보존하며 매칭 품질을 먼저 확인한다. 노출 대조는 사후 손익을 보고 비중을 맞추지 않고 개발 구간에서 정책을 설정한다.

### 실험 설정과 판정

| 항목 | 설계안 |
| --- | --- |
| 종목군 | 당시 거래 가능했고 식별을 확인한 국내 상장 구매자. 시장·주식 종류·가격 이력 기준은 데이터 감사 후 동결한다. 삼성전자·SK하이닉스는 재현 사례로 표시한다. |
| 시점·버전 | 공시 접수번호, 원문 위치, 원공시·정정, 법인–종목 매핑 버전을 기록한다. 관계는 신호 공시 전에 알려져 있었고 사건일에 유효해야 한다. 날짜만 있고 장중 가용 시각을 확인할 수 없으면 다음 세션을 가장 이른 후보로 둔다. 자료 지연을 복원할 수 없으면 그 행은 독립 운용 검증에서 제외한다. |
| 개발과 검증 | 이미 확인한 구간은 과거 재현과 진단용이다. 독립 구간 후보의 접촉 이력과 가격·공시 커버리지를 감사한다. 레이블의 보유 창이 경계를 넘는 행은 제거한다. 평가 기간은 독립 사건·세션·변경 주문 수와 최소 의미 효과를 기준으로 결정한다. |
| 주문·비용 | 기존 롱온리·현금 정책과 다음 거래일 시가 가정을 먼저 재현한다. 공식 시가 체결은 모의 가정으로 표시한다. 거래정지·결측·부분/미체결과 주문 크기 제약을 기록한다. 기존 왕복 0·20·40bp는 비교용 민감도이며 실측 비용이 아니다. |
| 주 지표 | 같은 세션에서 A3−A2의 평균 일별 비용 후 포트폴리오 수익 차이. 누적 차이, 최대낙폭, 시장 노출, 회전율, 비용 손익분기점도 보고한다. |
| 불확실성과 채택 | 같은 날 종목을 묶고 시간 의존을 고려해 짝지은 거래일 블록으로 구간을 추정한다. 사건 및 변경 주문이 너무 적거나 한 기업을 빼면 효과가 뒤집힐 때는 보류한다. 활성일과 전체 기간을 둘 다 표시한다. |
| 경제적 판정 | 데이터·누수 검증에 통과하고 주 비교가 사전에 합의한 효과와 비용·노출 조건을 충족할 때 모의 운용으로 진행한다. 성과가 나오지 않거나 확인이 불가능한 경우도 결과로 기록한다. |

### 실행 순서와 단계 종료 조건

| 단계 | 산출물 | 넘어갈 조건 |
| --- | --- | --- |
| 0 데이터 감사 | 날짜·가용 시점·가격·기업행동·원문·관계 커버리지 표 | 정정 전 미래 정보 차단 사례와 예외 집계, 독립 구간 후보 확인 |
| 1 과거 재현 | A0–A3 손익·포지션·거래 원장 | 기존 수치 대조와 불일치 이유 확인 |
| 2 진단·동결 | 사건창 초과수익, 커버리지, 매칭 품질, 노출/변경 주문 분석, 사전 등록본 | 비교·정책·검증 기간·판정선 확정 |
| 3 독립 검증 | 순성과 차이와 구간, 비용 민감도, 집중도, 위약·노출 대조 | 사전 판정에 따라 보류·기각·모의 운용 결정 |
| 4 모의 운용 | 새 공시의 신호→주문→모의체결 대조표 | 최초 불일치 단계와 가능한 조치를 기록 |

정확한 독립 기간, 최소 사건·변경 주문 수, 최소 개선 폭, 매칭 허용 범위, 노출 한도는 미확정이다. 데이터 감사와 개발 구간 검토 뒤 검증 결과를 보기 전에 정한다.
