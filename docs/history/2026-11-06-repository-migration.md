# 저장소 이전 기록 · 2026-11-06

기존 로컬 연구 프로젝트를 knowledge_graph 저장소로 구조화했다. 원본 온톨로지 v0.1은 적용 기준으로 유지하고, v0.2 XLSX와 FIBO 검토는 초안 영역으로 분리했다. 기존 폴더는 복구·비교를 위한 보존 사본으로 남겼으며 현재 서버는 새 경로에서 실행한다.

## 반영 내용

- ingestion / extraction / graph / storage 패키지와 통합 CLI 구성.
- 날짜 구간 수집기의 셸 히스토리 키 검색 제거. OPENDART_API_KEY 환경변수만 사용하며 미설정 시 데이터 생성 전에 실패.
- Mac·EC2 데이터 루트·출력·런타임·암호 경로를 환경변수로 분리.
- 원문 오류 XML을 정상 ZIP으로 저장하지 않도록 개선. TLS 인증서 검증 유지.
- 원문·이전 결과·참고 자료 46,301개 파일 약 4.34GB의 복사 SHA256 확인. 상세 인벤토리는 Git 제외 artifacts/migration에 보존.
- 20건을 새 구조에서 재실행하여 경제 값·날짜·범위·필드 위치·문서 해시 일치 확인. 파생 원문 경로만 변경.
- Neo4j 정상 종료 후 실제 저장소 84개 파일 복사·해시 대조. 같은 계정·DB를 새 경로로 이전해 인증정보를 유지하고 로그·설정을 재생성.
- 노드 332개·관계 600개, 원본 ID·관계 유형·양끝, 실제 문서 20개 경로, typed 수치/날짜·근거·재적재 검증.
- 단위 테스트 15개 통과. 실제 데이터가 없는 소스 전용 복사본에서도 통과. CLI 도움말 5종·키 누락 시 안전 실패 확인.
- Gitignore 및 작업 파일/스테이징 내용의 비밀정보 검사 작성. 이 저장소 로컬 pre-commit hook 활성화. 실제 Git index에 데이터나 파일을 stage하지 않음.
- README 최상단에 SVG 개요도와 편집 가능한 draw.io 원본 배치. EC2 Compose와 운영 문서 준비.

## 최종 검토에서 수정한 항목

1. 작업 파일에서 비밀 값을 지워도 index에 남을 수 있어 staged blob도 별도 검사.
2. 인증/쿼터 중단·부분 오류가 수집 성공으로 처리되지 않도록 종료 코드 전파.
3. EC2에서 컨테이너 기동 직후 import가 실패하지 않도록 인증된 bounded readiness 대기 추가.

각 수정은 재현 테스트가 실패함을 확인한 뒤 반영했다. 전체 테스트는 최종 15개 통과했다.

## 실행상의 결정

- 원본 폴더는 검증·롤백용으로 남김. 디스크에 보존 사본이 추가로 존재한다.
- Mac은 이미 검증한 Java 21 ARM64·native Community를 이전했다. EC2에는 이를 복사하지 않고 Linux용 Community 이미지/별도 영속 경로를 사용한다.
- 실제 AWS 리소스 생성·EC2 배포·데이터 업로드는 하지 않았다. 실행 문서·Compose 준비와 로컬 검증을 배포 완료로 표현하지 않는다.
- API 키를 히스토리에서 다시 읽거나 새 파일로 자동 복사하지 않았다. 수집 실행 전 사용자가 로컬 환경에 제공해야 한다. 기존 Neo4j 인증 파일은 비추적 .secrets에 권한 600으로 보존했다.
- 커밋·푸시는 하지 않았다. 원격에서 pull하려면 검토한 코드·문서를 커밋·푸시하는 후속 단계가 필요하다.

실제 파일별 이전 인벤토리, DB 대조, 비밀정보 검사 결과 및 수치 검증은 artifacts에 있다. 그 안의 실제 데이터를 Git 추적 대상으로 바꾸지 않는다.
