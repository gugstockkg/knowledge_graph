# TRACE 후속 연구 설계

## 출발점

현재 결과에서 가격 모형은 정확도 56.90%, 직접 공시는 56.30%, 거래 경로는 56.15%였다. 거래 경로와 직접 공시의 차이는 −0.15%p이고, 95% 구간은 −1.66~+1.71%p다. 테스트는 39거래일·659개 종목–거래일이고 비용 후 수익률도 모두 음수였다. 기존 입력을 감사한 기록에서는 거래 상대 공시 특성이 0보다 큰 행이 39개(5.9%)였다. 기존 결과는 거래 경로가 유의한 추가 예측력을 제공한다는 증거를 보여주지 않는다. [백테스트 원본](trace_economic_revision_2026.md) · [특성 감사](opendart_ontology_expansion.md)

원 TRACE의 비교 가능한 요소는 당시 공개 정보만 사용하고 근거가 있는 관계를 따라 신호를 가져온다는 점이다. 국내 적용에서는 온톨로지가 자료와 규칙의 유효성을 높이는 효과, 검증된 경제 경로가 예측에 주는 효과를 각각 측정한다. [TRACE](https://arxiv.org/abs/2603.12500)

## 우선 실험 — 거래 상대 공시의 건수에서 검증된 노출로

**가설** — 상대 기업이 공시를 냈다는 사실을 합산하는 것보다, 계약·제품·당사자 역할로 관련성이 확인되고 당시 유효한 경로를 사용하면 직접 공시 모형보다 예측에 추가 정보가 생긴다.

예를 들어 SK하이닉스의 설비투자 공시가 공개됐을 때, 넥스틴에 전달할 신호는 당시 유효한 계약의 공급자·구매자 방향, 검사장비 품목의 일치, 공시에 명시된 매출 대비 계약 규모를 각각 확인해 만든다. 공시에 특정 공장이나 프로젝트가 연결돼 있지 않으면 동일 프로젝트라고 확정하지 않는다. 제품군 관련성과 명시적 프로젝트 연결을 서로 다른 특성으로 기록한다.

| 조건 | 고정할 비교 |
|---|---|
| A | 기존 가격 모형. 비상승 기준선도 함께 기록 |
| B | A + 직접 공시. 기존 연구의 모델과 특성을 재현 |
| C | B + 기존 거래 상대 공시 건수 |
| D | B + 원문 검수된 역할·품목·시점·계약 규모를 담은 경로 특성 |
| 위약 | 같은 시기·업종 내에서 상대방을 바꾸고 가능한 한 연결 수를 맞춘다. 공시 밀도나 업종 동조만으로 효과가 재현되는지 본다 |

첫 비교는 기존과 같은 로지스틱 회귀와 동일 종목–거래일 표를 사용한다. 이후 동일한 후보 경로에 대해 식별자·시간·근거 가드레일 적용 전후를 비교하고, 제외된 경로와 그로 인한 커버리지 변화를 센다. 첫 실험의 1차 추정치는 새 테스트 기간에서의 **D 대 B 균형 정확도 차이**다. D 대 C와 위약 대조는 그래프 신호가 어디서 왔는지 해석하는 비교다.

### 입력과 평가 절차

1. **기존 결과 재현** — 원문·가격 버전, 학습 코드·비용을 고정해 기존 테스트 수치와 상대 공시가 있는 행 수를 재계산한다. 이미 확인한 2026년 결과는 재현과 탐색에 사용한다.
2. **연결 품질·커버리지 감사** — 고객 이름, 법인·증권 ID, 공급·구매 역할, 제품군, 공개시각, 계약 유효 구간을 확인한다. 제품·프로젝트 연결과 계약 상태별 표본 정밀도, 공개 시점에서 관측 가능한 비율, 실제 입력이 켜지는 종목–거래일 수를 보고한다. 미확인 링크를 0인 신호와 구분한다.
3. **시점 차단** — 신호는 진입 시점 전에 공개·확인 가능했던 근거만 사용한다. 공개 시간이 확보되지 않으면 기존 일 단위 규칙대로 다음 거래일부터 사용한다. 계약 유효 시점과 공시 공개 시점을 따로 저장하고 정정 이후에만 새 값을 쓴다. 시장 경로나 증권 식별자가 충돌하면 보류한다.
4. **새 테스트 구간 고정** — 기간 순서대로 학습·검증·테스트를 분리하고 동일 사건의 정정·후속 문서가 경계를 넘으면 사건 단위로 누출을 점검한다. 여러 거래일을 쓰는 목표변수에서는 라벨 기간이 경계를 넘는 표본을 제외한다. 현재 보유한 S3 원문은 확인 범위에서 2026년뿐이므로, 새 기간을 먼저 확보·고정하고 그전 결과는 탐색으로 표시한다.
5. **결과 보고** — 전체 종목–거래일, 사전에 정의한 경로 노출 집단, 주요 사건 유형에서 분모를 함께 제시한다. 균형 정확도를 주 지표로 하고 상승 F1, 확률 보정, 시점 위반 건수를 보고한다. 수익률은 기존 20bp를 재현하고 비용 민감도, 회전율, 최대낙폭을 함께 기록한다. 같은 거래일끼리 비교하고, 연속 거래일 블록으로 불확실성을 추정한다. 같은 경제 사건이 여러 종목에 영향을 주는 경우 사건 군집 민감도를 확인한다.
6. **판정** — D의 이득이 새 테스트나 위약 비교에서 유지되지 않으면 그래프의 예측 기여를 확인하지 못했다고 보고한다. 반대로 효과가 경로 노출 집단에 한정되면 커버리지와 전체 효과를 함께 제시한다.

## 가치가 있는 후속 가설

| 순서 | 가설 | 판별 방법 |
|---|---|---|
| 1 | **경제적 관련성**이 거래 상대 공시 건수보다 정보성이 높다 | 위 A–D와 위약 비교. 출처·시점이 확인된 경로만 후보에 넣는다. |
| 2 | **지배권·자금조달 단계**마다 별도의 신호가 있다 | 동일 사건의 체결, 납입·종결, 정정·철회를 구분한다. 직접 지배권 공시를 추가한 모형과, 검증된 지배·계열 경로까지 추가한 모형을 순차 비교한다. 수량·잠재 희석은 증권별로 보존한다. |
| 3 | **신호가 나타나는 기간**이 사건 종류에 따라 다르다 | 주 비교의 당일 시가→종가를 유지하고, 다음 1·5거래일과 시장·업종 조정 수익률은 사전 정의된 보조 분석으로 보고한다. 여러 조합을 검토한 경우 선택 기준과 전체 결과를 함께 낸다. |
| 4 | **기간 있는 분석 의견**이 확인된 원천 기록에 추가 정보를 준다 | 증권 ID로 RDF 사실과 Temporal LPG 의견을 연결한다. 당시 존재했던 의견만 쓰고, 미래 문서를 볼 수 있는 모델의 사후 생성 의견은 본 평가에서 제외한다. 검증된 사실만 쓴 모형과 사실+의견 모형을 같은 시험 구간에서 비교한다. |
| 5 | **다중 홉**은 약한 경로의 합산보다 제한된 조건에서 유효하다 | 1홉 기준을 고정한 뒤 2홉만 추가한다. 각 홉의 공개·유효 시점, 상품 또는 제품의 관련성, 다중 경로 중복 제거, 같은 업종 내 위약 엣지를 검사한다. |

그래프 질의 실험의 산출물은 **정답·필수 근거·시점 검증 결과**다. TRACE로 넘기는 산출물은 **공개 날짜와 경제적 유효기간이 확인된 경로 특성**이다. 두 실험을 연결하되, 질의 검증이 좋아졌다는 결과에서 가격 예측 성능을 추론하지 않는다.
