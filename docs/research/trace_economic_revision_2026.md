# 개정 공시 지식그래프의 주가 방향 예측 재실험

2026년 11월 27일 20:31 KST · EC2 CPU 실행 · [공개 연구 기록](https://gugstockkg.github.io/knowledge_graph/journal/2026-11-27-trace-backtest/)

거래 경로를 추가한 모형은 직접 공시 모형보다 정확도가 10월 1일~11월 6일에 **0.68%p**, 11월 9일~26일에 **0.54%p** 낮았다. 비용을 반영한 거래 성과는 앞 구간에서 거래 경로 모형의 손실 폭이 더 작았고, 뒤 구간에서는 더 컸다. 삼성전자와 SK하이닉스의 경우 거래 상대를 따라 추가 공시를 찾은 날이 늘었지만, 11월 구간의 수익률은 두 종목 모두 가격 모형을 밑돌았다.

## 연구 설계

[TRACE](https://arxiv.org/html/2603.12500v1)의 공개 시점 제한과 근거 추적을 적용했다. 원 논문은 자동 규칙 마이닝, 다중 홉 탐색, LLM 평가를 결합한다. 이번 연구는 먼저 개별 기업의 가격·공시와 이미 공개된 공급계약을 따라온 상대 기업의 공시를 단계적으로 추가해, 정보의 종류별로 성능이 어떻게 변하는지 측정했다.

- **출처와 범위.** EC2의 Neo4j 경제 사건 스냅샷에서 공급계약 1,294건, 계약 조건 정정 83건, 시설투자 발표 37건, 매출·영업이익 2,160개 관측값을 추출했다. 구매자까지 연결된 계약은 226건이다. 11월 후속 평가용 가격은 지수 두 개를 포함해 시세 187개를 요청했다. 지수 두 개와 종목명·기업 코드가 부합하는 종목 177개를 확보했고, 식별이 맞지 않은 8개는 제외했다.
- **표본.** 공시 기업과 공급계약의 확인된 당사자를 후보로 둔다. 삼성전자(005930), SK하이닉스(000660)는 기업 공시 없이도 전 거래일을 포함한다. 동일한 평가표는 모든 모형에 적용한다. 21개 연속 시장일 가격 확인이 안 되거나 거래 종목 식별이 모호한 행은 제외한다.
- **당시 정보.** 거래일 직전 세션까지의 가격과 진입일보다 앞서 공개된 공시를 사용한다. 이전 거래일부터 진입일 전까지 주말·휴일에 공개된 문서를 포함한다. 경로에는 신호 공시보다 앞서 존재하며, 알려진 계약 기간이 신호 공시일을 포함하는 관계만 쓴다. 같은 날짜의 변경 버전이 충돌하면 그 계약은 경로에서 제외한다.
- **대상값과 모형.** 시가→종가 수익률이 양수면 상승이다. L2 로지스틱 회귀의 규제 강도를 7~8월 검증 구간의 균형 정확도로 고르고 1~8월을 합쳐 두 평가 구간에 고정했다.
- **규칙.** 가격 모형은 1·5·20거래일 모멘텀과 거래량을 사용한다. 직접 공시 모형은 계약·정정·투자·실적 공시 건수 및 금액 요약을 추가한다. 계약 역할 모형은 구매자 노출, 상대 기업 수, 과거 유효 계약의 상대 기업 수를 추가한다. 거래 경로 모형은 유효 계약으로 연결된 상대 기업의 계약·투자·실적 공시 건수를 더한다. 실적 발표의 매출·영업이익은 같은 공시 한 건으로 세며 컨센서스 대비 실적차를 가정하지 않는다.
- **백테스트.** 상승 확률 0.5 이상을 시가 동일가중으로 매수해 종가 청산한다. 왕복 20bp를 차감하며 미진입일 수익률은 0으로 둔다. 샤프는 0% 무위험수익률과 연 252거래일로 환산한다. 날짜 단위로 짝지어 2,000회 재표집한 정확도 차이 구간은 표본 내 불확실성의 근사치다.

## 재현

- S3 비공개 연구 경로의 입력 묶음과 EC2 노드에서 내보낸 그래프 입력 해시를 검증했다. 결과 파일 SHA-256은 `5361604182fa4d1565a123c6614439930321adab6a898e479ef2e79f8fe9ef09`이다.
- EC2 CPU 실행 시간은 25.13초, 최대 RSS는 120,180KiB였다. GPU와 LLM API 호출은 사용하지 않았다. 로컬과 EC2의 수치는 절대·상대 허용오차 10⁻¹² 내에서 일치했다.
- 이 실험의 시세는 2026년 11월 8일 보관한 일봉과 후속 평가용으로 새로 받은 일봉을 구간별로 사용했다. 제공처의 수정주가 처리 및 실제 체결 가능성은 별도의 검증이 필요하다.

```bash
export PYTHONPATH=src

```
