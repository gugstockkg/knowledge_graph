# 주가 예측 TRACE 원형 재현과 변형 비교

원형은 Ding et al.의 주가 예측 TRACE를 뜻한다. 앞서 검토한 질의응답 TRACE의 경로 경험 재사용은 별도 아이디어다. [원형 논문](https://arxiv.org/html/2603.12500v1)

## 1. 동일 실험 재현 기준

| 구성 | 원문에서 확인한 설정 | 재현에 필요한 자료 |
|---|---|---|
| 데이터·평가 | S&P 500, 2022년 학습·2023년 평가, 다음 거래일 수정종가 방향. 원문 공개 이전 사용 금지 | 날짜별 종목과 가격, 시점별 그래프, 근거 뉴스·공시·통화 기록의 정확한 버전과 분할 |
| 규칙 학습 | 2~4 그래프 엣지의 관계열, 상승·하락 방향을 각각 규칙으로 생성, 방향 일치 비율, 마이닝 임계값 0.60 | 최소 지원 수, 실제 채굴 규칙과 전처리 구현, 규칙 동률 처리 |
| 탐색·판정 | 빔 8, 탐색 깊이 3, 가설 임계값 0.60, 최대 10개 점수화, 근거 5개. Qwen QwQ-32B 및 Qwen3-Embedding-8B | 동일 체크포인트·프롬프트·디코딩과 임베딩 전처리, 융합 가중치 |
| 매매 평가 | 평가 시작 시 전략별 상위 10종목 선정, 기간 중 리밸런싱 없이 보유, 원형 지표는 비용 제외로 명시됨 | 종목 순위 산식·동률 처리, 종목별 기대 출력, 동일한 수정가격과 평가 집계 코드 |

마이닝의 2~4개 엣지와 추론 최대 3개 엣지는 다르다. 우리 프로젝트의 회사 간 경제적 홉과도 다르다. Algorithm 1의 실행 순서와 근거 선택이 본문 설명과 다르게 읽히는 부분은 구현에서 선택을 숨기지 않는다. 예를 들어 의사코드는 검증 LLM이 근거 출력에 개입하기 전에 방향을 정한다. 가설이 없을 때 DOWN/0을 반환하는 동작도 원형 모드에서 보존하고, 보류는 별도 변형으로 둔다. [원문 §3, §5.5, 부록 A·C](https://arxiv.org/html/2603.12500v1)

공식 원문·공개 검색과 로컬 자료에서 저자 코드, 동일 S&P 500 그래프·원문 스냅샷과 원형 프롬프트를 확보하지 못했다. 동일 조건의 수치를 재현했다고 보고할 수 없다. S&P 500 원형과 OpenDART의 논문 기반 독립 재구현은 각각 보고한다. OpenDART 재구현에서 역할·금액·기간을 어떤 노드/엣지로 매핑했는지, 대체한 모델·데이터·프롬프트를 공개한다. 기존 1홉 규칙형 매매는 이 원형 대조군과 별개의 실험이다.

## 2. 같은 OpenDART 입력으로 비교할 변형

| 조건 | 원형 대비 바꾸는 항목 | 검증할 질문 |
|---|---|---|
| A. 원형 방식 | 원 논문의 규칙 채굴→빔 검색→방향 판정→시작일 종목 선정과 보유를 재구현 | 국내 자료와 정의된 그래프에서 원형 탐색이 작동하는가? |
| B. 매매 정책만 변경 | A의 규칙·탐색·방향 점수 그대로. 동일 종목에서 기준 보유/현금 정책에 대한 전환·청산만 별도 실험 | 시작일 종목 선정 효과와 기간 중 사고파는 효과는 각각 얼마인가? |
| C. 경로 선택만 변경 | 가격 정책·원문·후보 경로를 B와 동일하게 두고, 순위 기준을 비용 후 추가 손익의 보수적 추정으로 교체 | 방향을 잘 맞힌 과거 규칙과 주문을 바꿨을 때 유용했던 과거 규칙 중 어느 쪽이 낫나? |
| D. 최대 홉만 변경 | 선택한 방식에서 제한적 2 회사 홉을 1 회사 홉에 추가. 양쪽 계약과 제품·프로젝트 연결을 확인 | 깊이 추가의 순증분은 무엇인가? |

모형 단계의 차이는 공통 주문 정책과 가드레일을 적용한 대조로 측정한다. 원형의 Top-10 보유 비교는 별도로 유지한다. 경로 실험에는 **공급사 공시에 구매자로 직접 명시된 신호만 쓰는 전략**을 넣어, 기존 계약 그래프가 더한 정보를 빼서 비교한다. 모든 변형의 설정은 새로운 검증 구간에서 고정하고, 이미 읽은 하락장은 탐색 표본으로만 사용한다. 가드레일을 추가할 때는 적용 전후를 별도로 보고하고, 근거 없음을 하락으로 해석하는 동작을 제거하면 보류율과 커버리지를 함께 기록한다.

## 3. 제안 방법과 차이

원형 규칙의 신뢰도는 규칙이 발화한 과거 사례에서 방향이 맞은 비율이다. 제안 방식은 경로가 개입한 전략의 비용 후 손익에서 같은 종목·날짜의 기준 전략 손익을 뺀다. 경로 유형별 추정치에 지원 수에 따른 수축과 불확실성 보정을 적용하고, 충분하지 않으면 원래 포지션을 유지한다. 원형도 별도 매매 백테스트를 하지만, 본 논문의 탐색 규칙은 그 백테스트의 비용 후 추가 손익을 목표로 채굴하지 않는다. [제안 수식과 알고리즘](trace_algorithm_methodology.md)
