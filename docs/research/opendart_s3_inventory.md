# S3 OpenDART 원문 인벤토리와 지분·지배권 확장

EC2에서 `s3://fintos-dev-data-gugst5ck/raw/opendart/` 전체 키 목록을 읽었다. `documents` 아래 파일명에서 14자리 접수번호를 얻고 같은 접수번호의 ZIP·XML과 수집본 중복을 합쳤다. 접수 연도와 공시 제목은 가능한 경우 같은 S3에 있는 공시 목록과 대조했다. 메타데이터를 찾지 못한 원문 한 건은 접수번호의 연도를 사용했다.

| 접수 연도 | 고유 공시 | 제목 확인 | 제목 미확인 |
|---|---:|---:|---:|
| 2026 | 207,632 | 207,631 | 1 |

원문 객체는 ZIP 222,411개와 XML 153,459개였다. 고유 접수번호 모두에 ZIP이 있었다. 다른 접수 연도의 원문은 이 경로에서 확인되지 않았다. 예를 들어 제목에 2025년 결산기간이 들어간 사업보고서도 2026년에 접수했다면 2026년으로 계산했다.

| 지분·지배권 공시군 | 추출 후보 원문 |
|---|---:|
| 최대주주 변경 | 215 |
| 주식등의 대량보유 | 10,985 |
| 최대주주 변경을 수반하는 주식양수도 | 161 |
| 임원·주요주주 특정증권등 소유상황 | 18,636 |
| 사업·반기·분기보고서 | 14,901 |
| 합계 | 44,898 |

유형 상세는 EC2 `/var/lib/fintos-disclosure-kg/ownership-inventory-20261127/output/by_year_title.csv`에 있다. 제목의 앞쪽 정정 표시와 공백을 정규화하며 결산기간 등의 제목 정보는 보존한다. 지분·지배권 공시군 집계에서는 위 다섯 양식군으로 추가 분류한다.

확장 추출은 연도 제한 없이 이 인벤토리를 읽는다. 임원·주요주주 보고는 당사자와 기준일, 개인 보유량·비율의 DART 필드 태그를 읽는다. 정기보고서는 최대주주·특수관계인 소유현황 표에서 역할, 증권 종류, 기초·기말 수량과 비율을 찾는다. 주식양수도 공시는 당사자, 계약 관련 표·비고, 관련 공시와 정정을 원문에서 보존한다. 결과는 접수번호와 원문 키·해시·행 번호를 포함한 JSONL로 저장하고 대상 필드를 찾은 원문, 필드 미검출, 읽기 오류를 각각 집계한다.

## EC2 실행 결과

접수일 2026-01-02~11-26의 44,898건을 처리했다. 네 조각의 출력에서 접수번호 중복이 없음을 확인했다.

| 공시군 | 필드 검출 | 필드 미검출 | 읽기 오류 |
|---|---:|---:|---:|
| 최대주주 변경 | 215 | 0 | 0 |
| 대량보유 | 10,985 | 0 | 0 |
| 주식양수도 | 161 | 0 | 0 |
| 임원·주요주주 | 18,636 | 0 | 0 |
| 정기보고서 | 12,797 | 2,079 | 25 |
| 합계 | 42,794 | 2,079 | 25 |

25건 모두 선택된 ZIP에 해당 접수번호의 본문 XML이 없었다. 확인한 사례 `20260318000091`에는 감사보고서 첨부 XML만 있었다. 필드 미검출은 소유현황 표가 없는 경우와 지원하지 않는 양식이 섞일 수 있으므로 별도 원문 검수 대상으로 둔다. 필드 검출은 추출 정확도와 구분한다.

EC2 산출물은 같은 작업 디렉터리의 `extraction/summary.json` 및 `extraction/0`~`extraction/3`의 `ownership.jsonl`이다. 새 공시군은 추출까지만 실행했다. 사건 연결과 그래프 적재는 기존 두 양식에서 검증한 결과와 별도다.
