# TRACE 하락장 매매 검증 프로토콜

평가 구간은 기존 보관 자료와 같은 2026-10-01~11-26이다. KOSPI와 KOSDAQ의 첫 시가 대비 마지막 종가로 하락장을 확인한다. 이미 살펴본 기간이므로 결과는 후향적이며 별도의 미래 구간이 독립 검증에 필요하다.

주 기준은 삼성전자와 SK하이닉스에 첫 시가에 같은 금액을 배분해 마지막 종가까지 보유하는 매수 후 보유 전략이다. 거래 가능 시세가 모든 평가일에 확보된 두 종목을 사용한다. 현금 수익과 비용 이전 시장 지수는 참고값이다.

- 가격 전략의 목표는 직전 20거래일 수익률이 양수일 때 전체 배정액을 주식에 두고, 그 외에는 현금이다.
- 그래프 전략은 직전 평가 시점 이전 5개 거래 세션에 공개된 경로 신호가 양수면 매수 또는 계속 보유, 음수면 청산 또는 현금 유지한다. 순신호가 0이면 가격 규칙을 적용한다. 서로 충돌하는 같은 날짜의 계약 버전은 경로에서 제외한다.
- 경로의 방향 신호는 신규 공급계약은 양수, 이전 공개값과 비교 가능한 금액 정정은 증감 방향을 사용한다. 시설투자와 실적은 동일 품목과 비교 가능한 변화 방향이 확인되지 않아 이번 거래 규칙의 부호에 사용하지 않는다.
- 넓은 경로와 좁은 경로는 같은 매매 규칙을 쓴다. 넓은 경로는 기존 유효 계약의 상대 회사 공시를 사용하고, 좁은 경로는 추가로 공급사에서 구매자로 정보가 들어오는 방향, 공시와 경로의 품목 분류 일치, 양수 계약 규모, 고유 출처를 요구한다. 이는 저장된 원문 근거에 연결된 구조적 조건이며 개별 경로의 사람이 확인한 원문 정밀도는 별도다.
- 진입은 다음 거래일 시가, 보유 평가에는 야간 가격 변동을 포함하고, 마지막 종가에 청산한다. 왕복 20bp를 기본으로 편도 10bp, 0·40bp 민감도도 산출한다. 분할·배당으로 수익률의 의미가 달라지는 경우 수정주가 기준을 확인한다.
- 주 지표는 비용 차감 누적 수익률과 같은 매수 후 보유 대비 차이다. 최대낙폭, 시장 노출, 매수·매도 수와 실제 전략 간 포지션 변경도 보고한다. 표본이 적거나 조건을 충족한 경로가 켜지지 않으면 개선을 주장하지 않는다.

## 첫 결과 이후 추가한 대조

거래 로그에서 품목 일치만으로 금호타이어 공장 건설 공시가 삼성전자에 전달된 사례를 확인했다. 후향적으로 공급계약의 명시적 구매자 기업코드가 매수 대상과 일치해야 한다는 조건을 추가했다. 이 비교는 별도 거래처로 신호를 전파하는 효과와 구매자로 직접 명시된 기업이 공급사 공시에서 얻는 효과를 구분하는 데 사용한다. 같은 기간에 추가한 규칙의 성과는 독립 확인이 필요하다.
