# 데이터·DB 보존

- 원문(data/raw)은 immutable한 출처 자료로 취급한다. 재파싱은 processed/graph 출력으로 구분한다.
- 파일 이동 시 상대경로·크기·SHA256을 비교한다. 이번 이전 인벤토리는 artifacts/migration에 있으며 전체 목록은 Git에 넣지 않는다.
- Neo4j 저장소 파일은 동작 중 복사하지 않는다. 정상 종료 후 스냅샷/백업을 만들고 같은 버전에서 재기동 검증한다.
- Mac→EC2 초기 이전은 원문 또는 그래프 CSV 재적재를 기본으로 한다. OS별 바이너리나 실제 저장소 디렉터리를 무조건 복사하지 않는다.
- 다른 서버로 DB 자체를 이전하려면 사용 중인 Neo4j 버전의 neo4j-admin database dump/load 공식 절차를 적용하고 별도 테스트 DB에서 먼저 복원한다.
- API 키·Neo4j 암호는 원문 백업과 분리하고 권한을 제한한다. Gitignore는 백업 정책을 대체하지 않는다.
- 현재 단계는 20건 파일럿이다. 데이터의 의미·검토 상태·정정 연결을 바꾸는 마이그레이션에는 온톨로지/추출 버전과 검증 결과를 기록한다.
