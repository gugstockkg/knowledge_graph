# 조선·기자재 공급계약 수집 파일럿

`contract-pilot`은 로컬 OpenDART 원문에서 조선 관련 계약을 찾아 종목 일봉과 기사 참조를 연결한다. 기존 공시 수집과 별개로 실행한다.

```bash
python3 scripts/kg.py contract-pilot --start 2026-01-01 --end 2026-11-08 --with-prices
```

- `--end`는 한국 시간 기준 완료된 날짜다. `--limit` 기본값은 10이다.
- 기존 일별 목록과 ZIP을 읽는다. 대상 기업의 모회사 대리 공시와 조선 범위 밖 계약을 제외하고, 상장 상대방을 찾을 수 있는 건부터 선택한다. 영문 회사명이 병기된 경우 한글 법인명으로 대조한다. 대조 결과는 후보로 보존한다.
- 계약은 공시 접수번호로 관리한다. 정정은 원공시 접수번호가 명시되고 같은 회사에 속할 때만 연결한다. 연결하지 못한 정정 수를 매니페스트에 기록한다. 원문 확보가 계속되면 표본이 달라질 수 있으므로 분석에 쓴 `contracts.json`과 매니페스트를 함께 보관한다.
- 주가와 코스피·코스닥 지수는 기존 네이버 차트 경로에서 수집한다. 종목코드와 제공 종목명을 대조하고, 원문 해시가 맞는 캐시는 재사용한다. 새로 받으려면 `--refresh-prices`를 추가한다.
- 공시 다음 시장 거래일 시가에서 1·5번째 거래일 종가까지의 수익률을 같은 시간 구간의 시장 지수와 비교한다. 필요한 가격이나 미래 거래일이 없으면 결측 사유를 남긴다. 수정주가 여부와 업종 지수는 별도 확인이 필요하다.

`data/pilots/shipbuilding_contracts/2026-01-01_2026-11-08/`에 결과가 저장된다.

| 파일 | 내용 |
|---|---|
| `contracts.json` | 원문 ZIP 위치·파일 해시·필드별 원문 줄, 공급사와 상대방 매칭 |
| `prices.csv`, `price_sources.json` | 종목·지수 일봉, 출처·수집 시각·원문 해시 |
| `event_returns.csv` | 공급사·상대방별 수익률, 시장 수익률, 차이, 결측 상태 |
| `news_input_template.csv` | 직접 검토한 기사 메타데이터를 입력할 양식 |
| `news_references.json` | 검토된 기사 링크, 발행 시각과 공시일 대비 구분 |
| `manifest.json` | 표본 수, 시세 실패, 기사 연결 범위 |

빅카인즈 또는 언론사에서 사건과 일치하는 기사를 확인한 뒤 `news_input_template.csv`를 복사해 작성한다. 날짜는 YYYY-MM-DD, 공개 시각은 시간대가 있는 ISO 8601 형식이다. 시각을 확인하지 못한 경우 빈칸으로 두고, 기사 본문은 입력하지 않는다.

```bash
python3 scripts/kg.py contract-pilot --end 2026-11-08 --with-prices \
  --news-csv data/pilots/shipbuilding_contracts/2026-01-01_2026-11-08/news_input.csv
```

공시 시각을 확보하기 전에는 같은 날 기사의 선후관계를 미확정으로 둔다. 시세는 파일럿 대조용이며, 금융위 공식 시세와 업종 지수 연동은 후속 작업이다.
