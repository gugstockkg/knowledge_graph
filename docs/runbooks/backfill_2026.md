# 2026년 금융 지식그래프 데이터 수집

이번 수집 범위는 한국 시간 2026-01-01~2026-11-08이다. 날짜가 추가되면 마지막 완료일 이후만 증분 수집한다.

| 단계 | 수집 대상 | 재개 및 검증 |
|---|---|---|
| 1 | OpenDART 전체 공시 목록과 제공 원문 | 기존 수집 작업을 이어간다. 접수번호별 ZIP·상태와 일별 목록을 재사용한다. 11월 6~8일은 같은 백그라운드 작업에서 순서대로 처리한다. API의 원문 미제공과 요청 실패를 구분한다. |
| 2 | 국내 주식 일봉 및 코스피·코스닥 지수 | 기간 내 DART 공시에서 확인한 종목과 최신 DART 고유번호 파일의 종목코드를 합집합으로 만든다. 네이버 차트를 종목별로 받아 저장하고 종목명, 일봉 중복, 가격 형식을 검증한다. 기존 차트 원본을 재사용한다. |
| 3 | 정치·경제·국제 뉴스 메타데이터 | 빅카인즈 통합분류에서 정치·경제·국제와 그 하위분류를 OR 조건으로 선택하고 검색어 없이 조회한다. 한 번에 최대 2만 건이므로 날짜를 나눠 내보내고, 구간별 검색 건수와 파일 행 수를 대조한다. 다중 분류 기사는 기사 식별자로 중복 제거한다. |
| 4 | 커버리지 검증 | 접수번호별 공시 상태, 종목별 첫·마지막 거래일과 시세 실패, 월별 뉴스 건수 및 미수집 범위를 집계한다. 상장·폐지 이력과 수정주가를 확인한 뒤 분석용 데이터셋을 만든다. |

대량 가격 수집은 DART에서 식별 가능한 보통주 종목을 우선 대상으로 한다. KRX의 증권 단위 과거 상장 목록과 대조하기 전에는 우선주, ETF 등 전체 증권이나 상장폐지 종목의 완전성을 확정할 수 없다. 기존 네이버 차트 경로의 수정주가 여부도 미확인이다. 공식 KRX 시세로 교차 검증하려면 인증키와 서비스 승인 필요 여부를 확인한다.

원문, 가격, 기사 메타데이터, 인증키는 Git 제외 경로에 보관한다. 뉴스의 공개 시각을 모르면 날짜 정밀도를 그대로 유지한다. 2026-11-11에 뉴스 수집 범위를 정치·경제·국제로 변경했다. 기존 경제 검색 결과 18,797건은 재사용하며, 같은 기간의 정치·국제를 보완한 뒤 완료로 판정한다.

주가 작업 재개 명령은 다음과 같다. 이미 검증한 종목은 체크포인트를 읽어 건너뛴다. 인증이나 요청 제한 응답이 오면 현재 상태를 저장하고 멈춘다.

```bash
python3 scripts/kg.py bulk-prices --start 2026-01-01 --end 2026-11-08 \
  --corp-codes data/raw/opendart/reference/corp_codes_20261109.json
```

결과는 `data/market/bulk_naver_daily/2026-01-01_2026-11-08/` 아래에 있다. `universe.json`은 조회 대상과 식별 근거, `series/`는 종목별 관측값, `manifest.json`은 진행률과 실패를 기록한다. 코드가 같아도 회사명이 불일치하거나 복수 법인이 걸린 경우는 `identity_review`로 보관한다.

빅카인즈에서 날짜를 입력한 뒤 달력에서도 날짜를 선택하고 적용한다. 검색 결과 건수를 확인한 후 `STEP 03 분석 결과 및 시각화 → 데이터 다운로드 → 엑셀 다운로드`로 내보낸다. 2만 건을 넘기거나 파일이 생성되지 않는 구간은 더 짧게 나눈다. `data/news/bigkinds/2026-01-01_2026-11-08/monthly_export_plan.json`의 `verified_exports`를 보고 첫 미수집일에서 재개한다. 내려받은 파일은 `raw/`에 보관하고, 기사 식별자·일자·언론사·제목·URL·통합분류·기관 태그를 `metadata/`에 JSONL로 저장한다. 기사 본문과 발췌는 정규화 결과에 포함하지 않는다.
